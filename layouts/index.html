What GOBL does to your data

Send a partial document. Get back one that is complete, correct, and ready to share.

  1. Normalize

    Cleans up text, tax IDs, codes and units, and fills in the values that local rules imply, so the same input always gives the same output.

  2. Calculate

    Totals, discounts, charges and taxes, with precise decimals and no rounding errors, using the tax rates in force on the issue date.

  3. Validate

    Checks the schema, the tax ID check digits, and the rules of each country and addon. Problems come back as faults with codes and JSON paths.

  4. Sign

    Wraps the document in an envelope with a digest and ES256 signatures, and keeps the stamps and QR codes that tax authorities return.

  5. Convert

    Exports to local and international formats, and imports them back, detecting the format automatically.

Run it however you work

Go library
go get github.com/invopop/gobl: the core models, calculations and rules.
CLI
gobl build, validate, correct, sign, verify and convert from your terminal or CI, with every addon and converter included.
HTTP API
Run gobl serve, or add the handler to your own Go server, for the same API behind gobl.dev, described with OpenAPI.
MCP server
Let AI assistants and agents build, check and convert documents with gobl mcp, or the hosted /v0/mcp endpoint.
In the browser
The same Go code, compiled to WebAssembly and packaged as @invopop/gobl-worker on npm.
JSON Schema
Open schemas for every document, plus a Ruby gem and generators for other languages.
